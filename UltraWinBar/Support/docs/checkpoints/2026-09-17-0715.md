## Decisions

- **The C ABI lives in `ktav` behind a feature, not in a separate crate.**
  The operator's call, over a published `ktav-cabi` crate: one version axis
  instead of two. The shape matters more than the location — logic in
  `ktav::cabi` with NO `extern "C"`, symbols expanded by `declare_cabi!`
  into the caller. That removes the symbol-export risk rather than
  mitigating it.
- **`ABI_VERSION` stays 1 after adding a tenth symbol.** By the documented
  rule, adding an exported function obliges a bump — but version 1 has never
  shipped, so defining it as "ten symbols" is more honest than releasing 2
  as the first version anyone sees.
- **Dry run before publishing.** The operator's call, and it found the js
  failure that could not have been fixed after publication: a crates.io
  version can be yanked but never replaced.
- **CHANGELOG headings are dated at release time, never before.** 0.7.0 of
  the spec shipped with its Appendix A entry still reading "unreleased" and
  0.7.1 nearly repeated it; the drift check now enforces the date.
- **Binding shim tests were NOT bulk-moved into the crate.** Checked name by
  name: most were already covered. Only two genuinely uncovered properties
  moved — a writer refusal carrying its reason code, and `format` agreeing
  with `emit_canonical` at the ABI layer.
