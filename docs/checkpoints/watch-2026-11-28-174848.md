## Decisions
- Chose a short-key text approach for the prayer changes (name + frame strings per language, sentence composed in code) over adding them to `JewishDay` events, because existing tests count `Events` (a Pesach cell must have exactly one).
- Chose to mark V'ten Tal U'Matar on the civil day whose evening starts it ("from tonight's Ma'ariv"), consistent with the Hanukkah candles, over marking the Hebrew date 7 Cheshvan.
- Chose to put the new/full moon and eclipse signs at the bottom right of the cell (user's request), the top row keeps the candle, Omer and Hanukkah.
- Chose "Milui HaLevana" for the full moon (the user may prefer "Yareach Male"); "Molad Emet" for the true new moon.
- Chose Meeus' method with computed values over a table for eclipses and phases; verified with a Python prototype against NASA counts and known moments.
