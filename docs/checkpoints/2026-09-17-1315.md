## Decisions

- **`message` is appended LAST in the envelope, never inserted.** A host
  reading by name is unaffected by a longer object; one reading
  positionally still finds every old field where it was. `ABI_VERSION`
  therefore stays 1, and docs/CABI.md now distinguishes appending from
  inserting, which it did not before.
- **Agents never delete or rename.** The operator's call after a recent
  agent-caused data loss. Where a move is genuinely needed, the agent
  creates the new file, leaves the old one, and reports `old -> new`; the
  orchestrator executes it by hand. This cost one extra step and has not
  slowed anything down.
- **`versions/0.6` was deleted by hand, not by an agent** — 412 files,
  including its digest manifest, which is the one pair that must go
  together. The `"0.6.4"` profile in `validate_corpus.py` was KEPT: it is
  version-support code exercised by synthetic tests, not content.
- **Link correctness is checked mechanically, never by eye.** Moving 18
  editor documents broke 52 of 82 relative links. A resolver script plus a
  rule-based fixer now handle this; both live under
  `editor/.rush/stdin/`.
- **Report structural limits instead of forcing the number.** Go module
  roots, Cargo `tests/`, and the vscode extension cannot reach 7 entries
  without breaking discovery, the binary count, or the build. Each commit
  message says so plainly.
